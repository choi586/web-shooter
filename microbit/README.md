# micro:bit 설치와 보정

이 폴더에는 서로 다른 micro:bit v2에 넣을 코드 두 개가 있습니다.

- `wrist-sensor-a.ts`: 손목밴드에 넣는 무선 동작 센서 A
- `usb-receiver-b.ts`: 노트북에 USB로 연결하는 수신기 B

## 코드 넣기

1. [Microsoft MakeCode for micro:bit](https://makecode.microbit.org/)에서 새 프로젝트를 만듭니다.
2. 화면 위쪽의 **JavaScript**를 누릅니다.
3. 기존 코드를 전부 지우고 해당 파일의 코드를 붙여 넣습니다.
4. 다운로드한 `.hex` 파일을 각 micro:bit에 복사합니다.
5. A와 B 코드의 `RADIO_GROUP`과 `RADIO_BAND`가 서로 같은지 확인합니다. 안정화 6 버전의 기본값은 그룹 `147`, 밴드 `50`입니다.

## 손목 센서 A 보정

1. 손목밴드를 찬 상태에서 전원을 켭니다.
2. LED에 `N`이 보이는 동안 편안한 중립 자세로 약 0.6초간 멈춥니다.
3. 스파이더 포즈로 손목을 꺾고 그대로 멈춘 뒤 **B 버튼**을 누릅니다.
4. 체크 표시가 나오면 발사 자세 저장 성공입니다.
5. X가 나오면 중립 자세와 차이가 부족한 것입니다. 손목을 더 꺾거나 센서 장착 각도를 바꿔 다시 B를 누릅니다.

필요할 때 사용할 조작:

| 조작 | 기능 |
|---|---|
| A | 중립 자세 다시 저장 |
| B | 손목을 꺾은 발사 자세 저장 |
| A+B | 동작 판정 없이 무선 시험 발사 |
| 로고 터치 | 감도 `1 → 2 → 3` 변경. 1이 가장 민감, 기본값은 2 |

LED 표시는 중앙 점이 준비 완료, 과녁이 발사 대기, 별 모양이 송신을 뜻합니다. 안정화 버전은 A→B 단방향 Radio이므로 A에서 수신 확인 표시는 사용하지 않습니다.

## 수신기 B 확인

수신기 B를 데이터 전송이 가능한 USB 케이블로 노트북에 연결합니다.

| 조작 | 기능 |
|---|---|
| A | 손목 센서 없이 웹앱까지 시험 발사 |
| B | 현재 수신 상태를 USB Serial로 출력 |

LED 중앙 점이 켜져 있으면 준비 상태입니다. 우측 아래 점이 약 0.5초마다 깜빡이면 B의 메인 동작도 정상입니다. 별 모양은 웹 신호 수신을 뜻합니다.

## 현장 튜닝

- 웹이 너무 쉽게 발사되면 A의 로고를 눌러 감도 `3`으로 바꿉니다.
- 팔을 제대로 뻗어도 반응이 적으면 감도 `1`로 바꿉니다.
- 팔을 뻗었는데 빠지는 경우 먼저 A와 B를 1~2m 안에 놓고, 두 장치 모두 최신 코드인지 확인합니다.
- 같은 공간에 장치를 여러 세트 설치할 때는 세트마다 `RADIO_GROUP`을 다르게 정합니다.
- A는 배터리 팩, B는 노트북 USB 전원을 사용하면 됩니다.

## 연결 안정화 버전

현재 코드는 Radio를 **A→B 단방향**으로 사용합니다.

- A는 동작을 판정한 뒤 손목이 안정되는 220ms 후에 짧은 숫자 패킷을 **최대 출력으로 한 번만** 전송합니다.
- B는 수신 이벤트 하나를 웹앱에 한 줄만 전달합니다.
- B의 Radio 이벤트는 숫자 확인과 플래그 저장만 수행합니다.
- B는 ACK나 비콘을 Radio로 다시 전송하지 않습니다.
- USB Serial, RSSI 조회, 문자열 파싱, ACK, 화면 처리는 Radio 이벤트 안에서 실행하지 않습니다.
- 준비, 발사, 상태 신호는 모두 B의 메인 루프 한 곳에서 짧은 줄로 출력합니다.
- 부팅할 때 A에는 `A6`, B에는 `B6`가 표시됩니다. 이 표시가 없으면 이전 코드입니다.

이전 양방향 코드가 한쪽에 남으면 안정화 효과를 확인할 수 없습니다. **A와 B를 모두 최신 파일로 다시 다운로드**한 뒤 시험하세요. 새 그룹과 밴드를 사용하므로 한쪽만 업데이트하면 서로 통신하지 않습니다.

권장 내구 시험:

1. B만 연결한 상태에서 B의 A 버튼을 10회 누릅니다.
2. A를 켜되 움직이지 않고, B의 우측 아래 점이 계속 깜빡이는지 확인합니다.
3. A의 A+B 버튼을 20회 누릅니다.
4. 실제 손목 동작으로 50회 발사합니다.
5. 시험 중 웹앱 상단이 계속 `수신기 준비 완료`인지 확인합니다.

중앙 점은 그대로인데 우측 아래 점까지 멈추면 B의 메인 동작이 멎은 것입니다. `B4`가 다시 표시되면 B가 재부팅된 것입니다.

## USB Serial 형식

수신기 B는 `115200 baud`로 다음 줄을 보냅니다.

```text
R
H
W|sequence
T|sequence
```

`W`는 A에서 받은 실제 무선 발사, `T`는 B의 A 버튼으로 만든 시험 발사입니다. 웹앱은 안정화 6 형식과 이전 `WS1` 형식을 모두 읽을 수 있습니다.

손목밴드 장착 시 micro:bit LED 면을 바깥쪽으로 향하게 하고, 뒷면 좌상단의 금색 Radio 안테나 부분을 피부·밴드·배터리로 덮지 마세요. 팔을 뻗은 직후 `A6`가 다시 표시되면 무선 문제가 아니라 A의 전원 케이블이나 배터리 접촉 문제입니다.
